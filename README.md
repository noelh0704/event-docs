# 活動文件公版平台

活動資料填一次，行前通知、主持人稿、操作手冊、備品清單、新聞稿、致詞稿、社群貼文自動帶入，一鍵匯出 Word。
純靜態網站，放在 GitHub Pages 即可使用；AI 代寫另接一支中繼服務保管金鑰。

## 功能

| 功能 | 說明 |
|---|---|
| 共用資料 | 活動基本資料、流程表、人員分工、貴賓名單，七種文件共用 |
| 行前通知 | 四種對象各一份：參加者、講者／貴賓、工作人員、表演團體／廠商 |
| 主持人稿 | 基本資訊、貴賓唱名單、各環節講稿、突發狀況應對 |
| 操作手冊 | 目錄、基本資訊、工項分組、流程表、活動細流（含勾選框）、SOP、緊急應變、場地配置圖 |
| 備品清單 | 清點提醒、分區明細；可另存 CSV 給 Excel／Google 試算表 |
| 新聞稿 | 事前稿、事後稿各一份：發稿單位、主副標、內文、照片圖說、敬請刊登結尾 |
| 致詞稿 | 可列多位致詞人，依重點與分鐘數撰寫 |
| 社群貼文 | 一篇一個主題的系列貼文：規劃表、文案、固定標記單位、主題標籤（該篇＋系列固定）、搭配圖卡 |
| 匯出 | Word（.docx）、列印／PDF、複製純文字 |
| AI 代寫 | 貼企劃書自動整理活動資料；各文件一鍵產生初稿 |
| 專案檔 | 匯出／匯入 JSON，同事之間交接用 |

Word 格式規範已內建：字體最小 12 級、操作手冊含正式目錄（套用標題樣式）、圖片放在表格格子內。
檔名規則：`日期_活動名稱-文件名稱_v版號.docx`，每次匯出版號加一，不覆蓋舊檔。

## 上線到 GitHub Pages

1. 在 GitHub 建立一個空的公開 repo（例如 `event-docs`）。
2. 把本資料夾全部內容推上 `main` 分支。
3. repo 的 Settings → Pages → Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約一分鐘後，網址為 `https://<帳號>.github.io/<repo 名稱>/`。

## 開啟 AI 代寫

### 方式一：公司中繼服務（建議）

1. 到 <https://script.google.com> 新增專案，把 `proxy/Code.gs` 的內容整份貼上。
2. 左側「專案設定」→「指令碼屬性」，新增兩筆：
   - `ANTHROPIC_API_KEY`：Claude API 金鑰
   - `ACCESS_CODE`：自訂一組存取碼（給同事在網站上輸入）
3. 右上「部署」→「新增部署作業」→ 類型選「網頁應用程式」；執行身分選「我」，存取權選「所有人」→ 部署。
4. 複製網頁應用程式網址（結尾為 `/exec`）。
5. 回到平台，右上「設定」→ 選「公司中繼服務」，貼上網址與存取碼。

### 方式二：個人金鑰

平台「設定」→ 選「個人金鑰」，貼上 Claude API 金鑰。金鑰只存在該瀏覽器，適合個人使用。

## 資料存放與隱私

- 這個 repo 是公開的，**只放通用公版與虛構的範例活動，請勿把客戶資料提交進來**。
- 填寫的活動資料只存在使用者自己的瀏覽器（localStorage）。換電腦或清除瀏覽資料會消失，請用「匯出專案」備份。
- 使用 AI 代寫時，活動名稱、流程、分組與貴賓名單會送到 AI 服務；聯絡電話與信箱不會送出。「AI 匯入」則會送出你貼上的全部文字。

## 檔案結構

```
index.html            主頁面
css/style.css         樣式
js/config.js          全站設定（公司名稱、字體、AI 模型）← 要調整先看這裡
js/sample.js          範例活動（虛構）
js/templates.js       各種文件的公版（內容與版型）← 要改公版改這裡
js/render-html.js     預覽
js/render-docx.js     Word 匯出
js/ai.js              AI 代寫的提示詞與連線
js/app.js             介面與操作
proxy/Code.gs         AI 中繼服務（Google Apps Script）
vendor/docx.umd.js    Word 產生函式庫（docx 8.5.0）
test/                 測試腳本（不影響網站）
```

## 新增一種文件公版

1. 在 `js/templates.js` 新增一個 `buildXxx(ev)`，回傳文件模型，並在 `DOCS` 與 `build()` 登記。
2. 在 `js/app.js` 的 `SECTIONS` 新增對應的填寫區。
3. 需要 AI 代寫時，在 `js/ai.js` 的 `TASKS` 與 `js/app.js` 的 `APPLY` 各加一段。
